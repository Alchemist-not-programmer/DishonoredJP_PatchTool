# 翻訳データの利用条件

この文書は、Dishonored JPN Patch Tool の利用者または本プロジェクトの管理者が**新たに作成した翻訳文**にだけ適用されます。

対象となる翻訳文は、出典・著作権者・別途の利用条件が明記されていない限り、無償で利用、複製、改変、再配布および二次利用できます。クレジット表記は必須ではありませんが、可能な限り出典を残すことを歓迎します。

## 対象外

次のものには、この文書による許諾は及びません。

- Dishonored 本編、DLC、ゲーム内テキスト、フォント、UPK、INTその他のゲーム資産
- 既存の日本語化データ、既存の翻訳文、既存のDB、既存のフォント
- 第三者が作成・提供したデータおよびソフトウェア
- プログラム本体のソースコードおよび実行ファイル（[LICENSE](LICENSE) のMIT Licenseが適用されます）

これらには、それぞれの権利者または配布者が定めた条件が適用されます。第三者データを混在させて配布する場合は、そのデータについて必要な許諾を配布者自身で確認してください。
